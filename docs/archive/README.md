# Arsip dokumentasi

Folder ini menyimpan materi historis untuk jejak keputusan. Isinya **bukan dokumentasi utama** dan dapat bertentangan dengan implementasi terbaru.

## Isi

- `architecture/`: Architecture v2, v3, dan v4 yang telah digantikan oleh [Architecture v5](../architecture/architecture_v5.md).
- `initial_idea.md`: ide awal hackathon sebelum scope dipersempit.
- `research_notes.md`: kumpulan link dan catatan riset awal yang belum semuanya menjadi evidence terverifikasi.

Untuk penggunaan sehari-hari, kembali ke [indeks dokumentasi aktif](../README.md).
