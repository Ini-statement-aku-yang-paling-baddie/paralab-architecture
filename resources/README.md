# Resources

Folder ini berisi PDF pendukung konteks produk dan challenge. File di sini bukan executable source, dataset training, atau evidence ilmiah yang otomatis dipercaya sistem.

| File | Kegunaan |
|---|---|
| `PRD-ParaLab-AI.pdf` | product requirement awal |
| `ParaLab-AI-Alur-Layar.pdf` | referensi alur layar |
| `ParaLab-AI-Workflow-Logika.pdf` | referensi workflow dan logika |
| `Studi-Kasus-ParaLab-AI.pdf` | materi studi kasus |
| `ParagonCorp ... Smart Lab 2.0 ...pdf` | konteks challenge dan organisasi |

Catatan link dan eksplorasi awal dipindahkan ke `docs/archive/research_notes.md` agar tidak terlihat sebagai evidence yang sudah diverifikasi.

Evidence publik yang benar-benar dipakai pipeline harus masuk melalui `sources/` dan `scripts/build_public_evidence.py`, lengkap dengan provenance dan validation status.
